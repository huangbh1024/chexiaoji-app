**v0.1 说明（首版）**

1. 本页是「我的」Tab 的完整定义：**个人资料 + 车库资产 + 车主工具箱 + 系统设置 + 账号区**。
2. 品牌统一为「车小记」，设计稿顶部「里程账本」视为旧占位品牌；页面标题与首页一致。
3. 车库是「车辆资产总览」而不是第二个首页：只展示里程、本月能耗支出、保养预警与一条数据提示，不重复 Hero、趋势与构成。
4. 明确「全部资产」是一等范围，并定义汇总口径（§7.4），解决设计稿卡片数字无法自洽的问题。
5. 明确 P0 / P1：P0 交付「资料卡 + 车库 + 报表入口 + 设置只读 + 空错态」，其余入口以**「即将上线」**呈现，不伪造状态。
6. 修正设计稿中无数据源或不实的文案：安全行车天数、电池健康度、充电桩自动计费、云端已同步、OCR 凭证数、AES-256 / 端对端加密（§13.1）。
7. 退出登录依赖登录与会话模块，本期不展示可点击入口；登录接入后按 §6.6 启用。

## 1. 背景与目标

首页回答「这辆车现在怎么样」，账单回答「每一笔记了什么」，统计回答「钱花在哪、走势如何」，我的页回答：

1. **我是谁**——当前账号、车主身份、使用时长与记账积累。
2. **我有哪些车**——多车资产一览，快速切换查看每辆车的里程、本月能耗与保养状态。
3. **我能用什么服务**——报表导出、凭证、同步、离线等车主工具的入口与真实可用状态。
4. **我怎么配置这个 App**——单位、隐私、通知与关于信息。

设计目标：

- 首屏即可看到「个人资料 + 三枚使用统计」，向下依次完成 **车库 → 工具 → 设置 → 账号** 的纵向浏览。
- 车库切换 1 次点击完成，且**不改变首页当前车辆**，避免「逛资产」误改记账上下文。
- 每个入口都有明确的可用状态：能用则直达，不能用则标注「即将上线」，不产生点了没反应的死按钮。
- 复用首页 / 账单 / 统计的视觉 token 与组件，我的页不产生第二套卡片、胶囊与图标规范。

## 2. 用户与典型场景

| 用户 | 关注点 | 本页价值 |
| --- | --- | --- |
| 单车车主 | 车辆总里程、本月能耗、保养还剩多少 | 一次进入确认车辆与记账积累 |
| 多车家庭 / 公司用车 | 全部资产合计、逐车切换 | 车库总览与快速下钻 |
| 刚记账的新用户 | 记账天数、累计笔数 | 看到使用积累，形成正反馈 |
| 需要报销 / 对账的用户 | 账单导出与月度报表 | 从工具区直达报表页 |
| 注重隐私的用户 | 手机号掩码、数据存放位置 | 查看真实的数据说明，而不是营销话术 |
| 需要调整偏好的用户 | 单位、货币、通知 | 找到设置入口并知道当前取值 |

典型场景：

- **早上打开**：确认今天是否需要充电 / 加油，顺手看本月这辆车花了多少。
- **多车对比**：在「全部资产」看合计，再点某辆车看它的本月能耗与保养预警。
- **月末对账**：从「账单导出与报表」直接生成当月报表，不需要先进账单页。
- **保养前**：在某辆车的卡片上看到「1,574 km 后」或红色「已超期」。
- **隐私检查**：打开「隐私与数据」说明，确认手机号已掩码、数据存在本机。
- **版本排查**：从「关于与帮助」确认当前版本号。

## 4. 设计基线（Design Tokens）

### 4.1 色彩

沿用 `AppPalette` / `AppColors`，不新增颜色：

| Token | 值 | 本页用途 |
| --- | --- | --- |
| `background` | `#F8F9FF` | 页面底色 |
| `surface` | `#FFFFFF` | 资料卡、车辆卡、工具卡、设置卡 |
| `surfaceContainer` | `#EFF4FF` | 指标小格、图标底、分隔线、未选胶囊描边 |
| `onSurface` | `#0B1C30` | 标题、数值、选中胶囊底色 |
| `onSurfaceVariant` | `#64748B` | 副标题、说明文字 |
| `outline` | `#6C7A72` | 次要文字、未选图标 |
| `primary` / `primaryText` | `#00C48C` / `#006C4B` | 认证徽标、主数字、可用状态点、FAB |
| `secondary` | `#FC9D41` | 保养预警、燃油 / 混动强调 |
| `tertiary` | `#0EA5E9` | OCR 工具、纯电辅助强调 |
| `violet` | `#8B5CF6` | 隐私 / 设置类图标（可选） |
| `error` | `#BA1A1A` | 保养超期、危险操作 |
| `surface` + 60% | — | 卡片内三指标小格 |

规则：

- 动力类型颜色与图标沿用 `PowertrainVisual`（纯电绿、油电混动橙、插电混动蓝、燃油琥珀），不按设计稿单页另起一套。
- 工具图标底色为语义色 16% 透明度（`color.withValues(alpha: 0.16)`），深色主题同样适用。
- 强调条颜色：车库 `primary`、工具箱 `tertiary`、设置 `outline`。
- 颜色不是唯一信息载体：状态必须同时有文字（「即将上线」「已超期」「未开启」）。

### 4.2 字体与字号

使用 `AppTypography`：

| 元素 | 样式 | 说明 |
| --- | --- | --- |
| 顶部品牌 | `headlineMd`（20 / 700） | 与首页标题一致 |
| 资料卡昵称 | `headlineSm`（16 / 700） | 设计稿 20px 收敛为 16 |
| 资料卡签名 | `bodySm`（11 / 400） | `outline` |
| 统计数值 | `headlineSm`（16 / 700） | 千分位，超长自动缩放 |
| 统计标签 | `labelSm`（10 / 700） | `outline` |
| 区块标题 | `headlineSm`（16 / 700） | 左侧 4×16 强调条 |
| 胶囊文字 | `labelMd`（11 / 600） | 选中 `surface`，未选 `outline` |
| 车名 | `headlineSm`（16 / 700） | 单行省略 |
| 车牌 | `labelMd`（11 / 600） | 字距 +0.5，等宽感由字体本身提供 |
| 卡片指标数值 | `headlineSm`（16 / 700） | 单位 `labelSm`（10） |
| 工具标题 | `headlineSm`（16 / 700） | 两行内 |
| 工具副标题 | `bodySm`（11 / 400） | 单行省略 |
| 设置项标题 | `bodyLg` + `FontWeight.w700`（15 / 700） | 设计稿 15–16px，字重补到 700 |
| 设置项副标题 | `bodySm`（11 / 400） | 单行省略 |
| 尾部说明 | `labelSm`（10 / 700） | `outline` 60% |

### 4.3 圆角、间距、阴影

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 页面边距 | `pagePadding` 16 | 左右一致 |
| 模块间距 | 20 | 资料卡 / 车库 / 工具箱 / 设置之间 |
| 模块内间距 | 12 | 标题与内容、胶囊与卡片 |
| 卡片圆角 | `radiusCard` 16 | 设计稿 24–28 收敛为 16，与全站一致 |
| 胶囊 / 按钮 | `radiusPill` 999 | 全圆角 |
| 图标容器 | 16 | 车辆动力图标 48×48；工具图标 40×40；设置图标 36×36 |
| 指标小格 | 8 | 三列等分 |
| 卡片阴影 | `cardShadow` | 资料卡、工具卡、设置卡 |
| 车辆卡阴影 | `selectedShadow`（绿色） | 仅选中 / 当前卡使用；全部资产卡同样使用 |
| 底部留白 | `contentBottomPadding + bottomInset` | 不被导航与 FAB 遮挡 |

### 4.4 动效

| 场景 | 动效 |
| --- | --- |
| 车辆胶囊切换 | 底色 / 文字色 180ms 过渡 |
| 车辆卡内容替换 | 120ms 淡出 + 缩放 0.99 → 1.0，禁止整页跳动 |
| 卡片按下 | 0.97 缩放（120ms），工具卡与设置行一致 |
| 设置按钮定位 | 点击资料卡齿轮后 `ensureVisible` 滚动到设置区（250ms） |
| 下拉刷新 | 系统 `RefreshIndicator`，主色 |
| 减少动效 | `MediaQuery.disableAnimations` 为真时取消缩放与淡入，仅保留即时切换 |

### 4.5 适配

- 内容最大宽度 448，水平居中；页面边距 16；不出现横向滚动（胶囊条自身横向滚动除外）。
- 320 / 375 / 390 / 430pt 下：三枚统计、三列指标不换行；数值过长时 `FittedBox(scaleDown)` 或降级字号。
- 底部安全区：导航高度 + `bottomInset`；滚动内容底部追加 `contentBottomPadding + bottomInset`。
- 字号放大 1.3 倍时，卡片高度自适应；标题最多两行，副标题单行省略；禁止文字溢出。
- 深色模式：卡片、胶囊、指标格、弹层全部使用 palette；不出现白底白字或硬编码白色描边。

## 6. 模块需求

### 6.1 顶部栏

- 左侧：36×36 圆形头像（渐变底 + 昵称首字 + 2px 主色描边与在线点），右侧 8px 间距为品牌名「车小记」。

### 6.2 个人资料卡

## 7. 数据口径与格式化

### 7.1 指标定义

| 指标 | 定义 |
| --- | --- |
| 记账天数 | `today - firstRecordAt.date + 1`，本地时区；无记录为 0，展示「— 天」 |
| 累计记录 | 账号全部车辆、全部历史、未删除的记录数；含所有分类 |
| 关联车辆 | 车辆列表长度；已删除 / 归档车辆不计 |
| 当前总里程 | 车辆最新仪表里程；全部资产为各车里程之和 |
| 本月能耗支出 | 当前自然月内 `charging` + `fuel` 记录的金额之和（退款按负值计入） |
| 本月能耗量 | 同口径记录的 `metrics.kwh` / `metrics.liters` 之和 |
| 本月能耗笔数 | 同口径记录条数 |
| 累计能耗成本 | 账号 / 车辆历史平均每公里能源成本，整数分/公里；用于车辆副标题 |
| 保养剩余 | `remainingKm`；超期为负值，展示绝对值 + 「已超期」 |
| 保养紧迫度 | 先取剩余里程最小且 > 0 的车辆；若全部超期，取超期最多（剩余最小）的车辆 |

### 7.2 时间口径

- 「本月」= 本地时区自然月 1 日 00:00 至当前时刻。
- 记账天数按自然日计算，不按 24 小时窗口。
- 跨年、闰年、月末 23:59 记录归属当月，不做 UTC 偏移。
- 数据更新时间 `dataUpdatedAt` 用于「数据更新于 …」；无缓存不展示。

### 7.3 格式化

| 场景 | 规则 | 示例 |
| --- | --- | --- |
| 统计计数 | 千分位，无小数 | `1,248 笔`、`4 辆` |
| 天数 | 整数 + 「天」 | `409 天` |
| 卡片金额 | 千分位、一位小数、¥ 前缀 | `¥312.4`、`¥1,148.2` |
| 汇总金额 | 千分位、取整、¥ 前缀 | `¥1,286` |
| 每公里成本 | 两位小数 | `¥0.18/km` |
| 里程 | 千分位整数 | `18,426` |
| 能耗量 | kWh 保留一位，整数时省略小数；L 保留两位 | `184 kWh`、`5.2 L` |
| 平均单价 | `¥{两位小数}/{单位}` | `¥1.33/kWh`、`¥8.16/L` |
| 车牌 | 原样，字距 +0.5 | `粤B·D82K6` |
| 手机号 | 服务端掩码，客户端原样展示 | `138 **** 9208` |
| 版本号 | `v` + 版本，不含 build 号 | `v1.0.0` |
| 空值 | 统一「—」 | `— 天`、`— km` |

### 7.4 全部资产汇总规则

| 字段 | 规则 |
| --- | --- |
| 车辆数 | `vehicles.length`；与胶囊徽标一致 |
| 总里程 | 各车 `odometerKm` 求和 |
| 本月能耗支出 | 各车本月 `charging + fuel` 金额求和 |
| 本月能耗量 | 不做跨能源相加：仅当全部车辆为同一种能源时展示 kWh 或 L；混合时只展示金额与笔数 |
| 本月能耗笔数 | 各车同口径记录数之和 |
| 保养预警 | 按 §7.1 紧迫度取一辆，副文标注「{车辆简称} · {剩余}km 后」或「{车辆简称} · 已超期」 |
| 动力构成 | 按 `PowertrainType` 分组计数，文案「纯电 x · 混动 y · 燃油 z」；无某类时不显示 |
| 数据提示 | 「本月共 {n} 笔能耗记录 · 合计 ¥{金额}」；n = 0 时「本月暂无能耗记录」 |

## 10. 非功能需求

- **性能**：我的 Tab 首次进入 ≤ 1s 可交互；车辆切换 ≤ 300ms（命中缓存 ≤ 100ms）；页面滚动 60fps；工具与设置区不触发额外网络请求。
- **数据量**：车库仅请求当前月份聚合；全部资产最多 10 辆车（接口限制），车辆胶囊可横向滚动；不因车辆数增加产生 N+1 阻塞首屏。
- **主题**：浅 / 深色完整覆盖；卡片、指标格、胶囊、弹层、骨架屏均可读；不使用硬编码颜色（动力 / 分类语义色除外）。
- **无障碍**：
  - 资料卡整体语义：「林漪，认证车主，记账 328 天，累计 142 笔，关联 3 辆车」。
  - 车辆卡语义：「比亚迪 汉 EV，粤B·D82K6，总里程 18,426 公里，本月能耗支出 312.4 元，保养剩余 1,574 公里」。
  - 工具卡语义包含状态；设置行语义包含当前值。
  - 点击区域 ≥ 44×44；颜色不作为唯一区分；字号放大 1.3 倍不截断关键数字。
- **本地化**：中文、人民币、公里、kWh、L；文案集中管理，不散落硬编码。
- **安全与隐私**：
  - 客户端不存储完整手机号；掩码由服务端返回。
  - 不在未实现加密时展示加密承诺；隐私说明必须与实际行为一致。
  - 车牌、手机号不进入埋点参数。
- **稳定性**：任一模块失败不白屏；无车辆、无记录、接口超时不崩溃；快速切换不出现旧车数据覆盖新车。
