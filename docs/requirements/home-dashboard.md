## 1. 背景与目标

车小记面向**一人多车、纯电 / 混动 / 燃油**车主，记录车辆能耗与各类开销。首页是用户打开 App 后看到的第一屏，也是使用频次最高的页面。

首页要在一屏内回答四个问题：

1. 这辆车**这个月花了多少钱**？
2. **每公里成本**是多少，比上月贵了还是便宜了？
3. 车**能耗**多少，**下次保养**还有多远？
4. 最近都记了哪些账，**怎么快速记一笔**？

设计目标：

- 核心信息一屏可见，无需滚动即可看到「综合每公里成本 + 双指标卡」。
- 记账入口不超过 1 次点击（中央 FAB）。
- 多车用户 1 次点击切换到任意车辆，所有模块联动刷新。
- 视觉上以「能耗 = 绿、其他开销 = 橙」建立稳定的色彩语义。

## 2. 用户与典型场景

| 用户 | 特征 | 首页关注点 |
| --- | --- | --- |
| 纯电车主（设计稿示例：林漪，比亚迪汉 EV） | 家充 + 公共快充，通勤为主 | 充电成本、百公里电耗、本月花费 |
| 混动 / 燃油车主（示例：丰田凯美瑞双擎） | 加油为主，偶尔充电 | 加油开销、油耗、每公里成本 |
| 多车家庭 / 公司用车 | 3 辆及以上，有备用车、闲置车 | 车辆切换、闲置车标签、各车独立账本 |

典型场景：

- **充电后**打开 App，点 FAB 记一笔充电费用，回到首页看到本月成本变化。
- **月初复盘**：查看上月花费趋势、开销构成，判断哪类支出偏高。
- **保养前**：首页「下次保养」提示还剩 1,574 km / 约 22 天，决定预约时间。
- **换车开**：横滑切换车辆，页面所有指标切换为该车数据。

### 4.3 圆角、间距、阴影

- 页面外边距 16px，模块纵向间距 20px（Hero 上下 16–20px），卡片内边距 16px。
- 卡片圆角 16px；车辆卡 16px；图标容器 8–16px；标签/胶囊全圆角；分类色标签 6px。
- 卡片阴影：`0 8px 24px -4px rgba(15,23,42,.04)`，内描边 `1px rgba(255,255,255,.8)`。
- 车辆选中卡：`2px #00C48C` 边框 + `0 12px 28px -6px rgba(0,196,140,.16)`。
- Hero 卡：渐变 `#00C48C → #05B380 → #0A8C66`，外阴影 `0 12px 32px rgba(0,196,140,.22)`，叠加有机波浪纹理与光晕。
- FAB：56×56，渐变绿，外发光 `0 12px 24px -4px rgba(0,196,140,.45)`，白边环 4px。
- 底部导航：白色 90% + 20px 背景模糊，顶部圆角 16px，上边阴影。

### 4.4 适配

- 移动端竖屏，内容区最大宽度 448px 居中。
- 覆盖 375–430pt 宽度；左右安全区 + 底部安全区。
- 明暗两套主题（深色稿已有）；图表、卡片、导航均需适配。
- 页面整体纵向滚动；顶部栏 sticky 半透明模糊；底部导航 fixed。
- 内容区底部预留 112px，避免被导航栏与 FAB 遮挡。

## 6. 模块需求

### 6.1 顶部栏

**展示内容**

- 左侧圆形头像（40×40，白色描边 + 阴影），右下角 12×12 绿色在线/状态点。
- 头像右侧两行：第一行问候语（11px，次要色），第二行页面标题「里程账本」（20px，700）。
- 右侧操作胶囊（白底 80% + 轻阴影 + 白描边），内含 3 个 32×32 圆形图标按钮：
  - 月亮：深色 / 浅色模式切换。
  - 调色盘：主题色 / 皮肤切换（P2）。
  - 铃铛：消息中心；有未读时右上角 6×6 红点（`#BA1A1A`）。

**交互与规则**

- 头像点击 → 「我的」页；未登录时显示默认头像，点击 → 登录页。
- 问候语按本地时间：05:00–10:59 早上好；11:00–12:59 中午好；13:00–17:59 下午好；18:00–22:59 晚上好；23:00–04:59 夜深了。昵称取用户资料，过长省略，最多 8 个字符。
- 顶部栏使用页面底色 80% + 高斯模糊，滚动时不改变高度；状态栏文字颜色随明暗主题切换。
- 通知红点仅表示「有未读」，进入消息中心后清除；消息中心本期是否实现见 Q9。

**验收**

- [ ] 滚动时顶部栏固定在状态栏下方，背景模糊可见内容穿过。
- [ ] 切换深色模式后顶部栏、图标、文字同步变色，无白块闪烁。
- [ ] 未读数 > 0 时显示红点，= 0 时隐藏。

### 6.2 我的车辆

**展示内容**

- 区块标题「我的车辆」（16px / 700）+ 绿色波浪装饰线（仅装饰，24×8 SVG）。
- 标题右侧分页指示器：圆角胶囊底，当前页为 16×6 绿色长条，其余为 6×6 灰点；数量 = 车辆数（最多显示 5 个，超过时显示省略）。
- 最右侧「管理车辆」文字按钮 + 调节图标（tune），绿字浅绿底胶囊。
- 横向滚动车辆卡（snap 滚动，卡宽 192px，间距 12px）：
  - 车辆图标（28×28 圆角方块，按动力类型：纯电=闪电 / 燃油=油枪 / 混动=电动车）。
  - 车辆名称（16px / 700，单行省略），如「比亚迪 汉 EV」。
  - 车牌（11px 次要色），如「粤B·D82K8」。
  - 动力与里程胶囊，如「纯电 · 18,426 km」「油电混动 · 46,210 km」。
  - 状态标签（右上角，仅非默认车）：备用 / 闲置，10px 灰底胶囊。
  - 选中卡：2px 绿色边框 + 右上角绿色勾选徽标；未选中卡：1px 浅灰边框。
  - 卡片右下角有淡色光斑装饰。
- 末尾「添加车辆」卡：宽 80px，虚线边框，圆形 + 号 + 10px 文案。

**交互与规则**

- 点击车辆卡：切换选中车辆，所有数据模块（Hero、双指标、趋势、构成、最近记录）以该车数据整体刷新；切换后分页指示器同步。
- 横向滑动：卡片滚动时，指示器应跟随（滚动结束后以最近吸附卡为准）；snap 对齐。
- 「管理车辆」→ 车辆管理页；「添加车辆」卡 → 添加车辆向导（独立页）。
- 车辆数量：1 辆时仍显示指示器（单点）；达到上限（建议 10 辆）时「添加车辆」卡置灰并提示。
- 当前车辆选择需本地持久化，冷启动恢复上次选中车辆；若该车已删除则回到默认车辆。
- 首页展示的车辆顺序 = 用户设置的排序；默认车辆排第一。

**状态**

- 加载中：3 个骨架卡（192×120 灰色圆角块）+ 一个 80px 添加卡占位。
- 无车辆：不展示卡片，显示空状态卡「还没有车辆，添加爱车后开始记账」+「添加车辆」主按钮；其余模块显示空数据占位，不请求接口。
- 接口失败：显示 1 行错误提示 + 重试，不影响其他模块已缓存数据。

**验收**

- [ ] 切换车辆后 300ms 内所有模块出现加载骨架，数据到齐后整体替换，不出现新旧车辆数据混排。
- [ ] 选中卡有绿框与勾选标记，非选中卡无。
- [ ] 备胎 / 闲置标签只在非默认车上出现（设计稿如此；如需任意车可标记见 Q10）。
- [ ] 分页指示器与当前选中卡一致。
- [ ] 冷启动恢复上次选择。

### 6.3 综合每公里成本 Hero 卡

**展示内容**

- 全宽渐变卡（绿），背景含两层有机波浪 + 左右光晕。
- 顶部左：速度图标 + 「综合每公里成本 · 本月」（11px / 600）。
- 顶部右：环比胶囊（半透明白底 + 模糊 + 白描边），带趋势箭头：
  - 下降：「较上月 -8.2%」（图标 trending_down）。
  - 上升：「较上月 +x.x%」（图标 trending_up，文案与箭头改为白色/浅色，不使用红色，避免与「亏损」语义混淆）。
  - 上月无数据：「较上月 —」。
- 核心 KPI：`¥`（26px）+ 数值（38px / 800）+ `/km`（13px）。
- 底部磨砂玻璃三列指标（白色 10% 底 + 模糊 + 白描边，圆角 16px）：
  - 本月花费：`¥1,286`
  - 本月里程：`2,140 km`（km 为小字）
  - 能源成本：`¥0.18/km`（/km 为小字）
  - 列之间 1px 白色 20% 竖分隔线（第一列无）。

**计算口径**

- 综合每公里成本 = 当月该车全部记账金额之和 ÷ 当月行驶里程。
- 能源成本/km = 当月能源类（充电 + 加油）金额 ÷ 当月行驶里程。
- 展示保留 2 位小数（设计稿 `0.60`、`0.18`）。
- 当月里程 = 月末里程表读数 − 月初里程表读数（取该车当月里程记录的最大/最小值差）；无里程记录时按记账填写里程累加；仍无数据则显示 `0` 并在点击时提示「补充里程后更准确」。
- 当月无任何记账：KPI 显示 `¥0.00`，三列均为 0，并在卡底追加一行「本月还没有记录，点 + 记一笔」轻提示。

**交互**

- 卡片本身无点击行为（P1 可点击跳转统计页，见 Q11）。
- 数字变化时使用 300ms 数字滚动动画（首次进入不做）。

**状态**

- 加载中：渐变卡显示骨架（数值位置灰白条）。
- 上月无数据、里程为 0 等边界按上述规则显示「—」或 0。
- 里程为负（补录跨月记录导致）→ 按 0 处理并上报异常日志。

**验收**

- [ ] 三列数值与开销构成合计、趋势合计一致。
- [ ] 环比与「比上期少 ¥116」的基期相同（上月/上一周期）。
- [ ] 深色模式下渐变、白字、磨砂底仍清晰可读。
- [ ] 数值 38px 在 375pt 宽度下不换行、不被裁切。

### 6.4 双指标卡

两卡并排，间距 12px，等宽，16px 圆角白卡。

**(a) 平均能耗卡**

- 左上：闪电图标（绿底浅绿圆角方块）+「平均能耗」（11px 次要色）。
- 主数值：「14.8」（26px / 700）+ 单位「kWh/百公里」（11px 灰）。
- 底部 sparkline 曲线（高 32px，绿色 2.5px 描边 + 渐变面积），展示近 7 次记录的能耗走势；不足 2 个点时不画线。

规则：

## 7. 数据口径与格式化

### 7.1 指标定义

| 指标 | 公式 | 边界 |
| --- | --- | --- |
| 本月花费 | Σ 当月该车记账金额 | 无记录 → 0 |
| 本月里程 | 当月里程表读数 max − min；否则 Σ 记账里程 | < 0 → 0；无 → 0 |
| 综合每公里成本 | 本月花费 ÷ 本月里程 | 里程 = 0 → 0.00 或「—」（建议 -），保留 2 位 |
| 能源成本/km | (充电 + 加油) ÷ 本月里程 | 同上 |
| 平均能耗 | 能源量 ÷ 本月里程 × 100 | 纯电 kWh、燃油 L；保留 1 位 |
| 保养剩余里程 | 保养周期 −（当前里程 − 上次保养里程） | 可为负（超期） |
| 保养剩余天数 | 剩余里程 ÷ 近 30 日日均里程 | 日均为 0 → 不显示 |
| 分类占比 | 分类金额 ÷ 总金额 × 100 | 四舍五入整数 |
| 环比 | (本期 − 上期) ÷ 上期 × 100 | 上期为 0 → 显示「—」 |
| 每公里成本（单笔） | 单笔金额 ÷ 里程增量 | 增量 ≤ 0 → 不显示 |

### 7.2 时间口径（待确认，见 Q3）

- 「本月」建议为**自然月**（每月 1 日 00:00 至月末），Hero、开销构成、最近记录共用。
- 趋势默认范围「30天」建议为**滚动 30 天**（含今天），与「本月」不同；若产品要求统一，改为自然月并调整默认选中。
- 时区固定设备本地时区；跨时区旅行不做特殊处理。

### 7.3 格式化

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 聚合金额 | 千分位，四舍五入取整 | `¥1,286` |
| 明细金额 | 千分位，保留 2 位 | `-¥51.10` |
| 每公里成本 | 保留 2 位 | `¥0.60 /km` |
| 里程 | 千分位整数 | `18,426 km` |
| 能耗 | 1 位小数 | `14.8 kWh/百公里` |
| 百分比 | 整数 + `%`，下降带 `-` | `-8.2%`、`30%` |
| 日期 | 今天 / 昨天 / M月D日 / YYYY年M月D日 | `今天 08:42` |
| 空值 | 统一 `—` | `¥—` |

## 10. 非功能需求

- **性能**：4G 冷启动首屏可交互 ≤ 2s；首页数据请求 ≤ 1.5s（P90）；滚动 60fps；图表使用 GPU 绘制，避免每帧重建整个页面。
- **包体**：图表库选型优先轻量（fl_chart 或自绘 CustomPainter）；字体按需子集化。
- **主题**：浅色 + 深色，跟随系统或用户设置；切换即时生效，无需重启。
- **无障碍**：金额卡片整体可朗读（如「本月综合每公里成本 0.60 元」）；颜色不作为唯一区分手段（分类均有文字）；支持系统字体缩放至 1.3 倍不截断关键金额。
- **本地化**：本期仅中文、人民币、公里、kWh、L；文案集中管理，为后续多语言预留。
- **安全与隐私**：车辆、账单按用户隔离；日志与埋点不得上传车牌、地点等敏感明文。
- **稳定性**：所有模块可独立降级，任何单个接口失败不导致白屏。
