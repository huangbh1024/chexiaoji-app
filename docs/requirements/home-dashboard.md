**v0.2 相对 v0.1 的变更**

1. 页面标题由「里程账本」改为「车小记」。
2. 车辆区覆盖四类动力（纯电 / 油电混动 / 插电混动 / 纯燃油），并支持点选车辆后全模块联动切换。
3. 平均能耗卡支持单能耗与「电 + 油」双能耗两种形态，并随动力类型改变标题、胶囊与单位。
4. 下次保养在进度 > 80% 时进入红色警示态，文案追加「即将保养」。
5. 上涨环比（Hero、趋势）使用玫红 / 红色，不再是统一白色。
6. 明确 **Hero 为自然月口径、趋势为滚动区间口径**，两者独立计算，不要求数值相等。
7. 开销构成分类随车辆动态变化（4–6 类），隐藏零金额分类。
8. 最近记录副信息按分类区分：充电 `¥/km`、加油 `¥/L`，其余不显示。

## 1. 背景与目标

车小记面向**一人多车、纯电 / 混动 / 燃油**车主，记录车辆能耗与各类开销。首页是用户打开 App 后看到的第一屏，也是使用频次最高的页面。

首页要在一屏内回答四个问题：

1. 这辆车**这个月花了多少钱**？
2. **每公里成本**是多少，比上月贵了还是便宜了？
3. 车**能耗**多少，**下次保养**还有多远？
4. 最近都记了哪些账，**怎么快速记一笔**？

设计目标：

- 核心信息一屏可见，无需滚动即可看到「综合每公里成本 + 双指标卡」。
- 记账入口不超过 1 次点击（中央 FAB）。
- 多车用户 1 次点击切换到任意车辆，所有模块联动刷新，且能清楚感知「已切换」。
- 以「能耗 = 绿、其他开销 = 橙」建立稳定的色彩语义，并按动力类型区分车辆卡。

## 2. 用户与典型场景

| 用户 | 动力类型 | 关注点 |
| --- | --- | --- |
| 纯电车主（示例：比亚迪 汉 EV） | 纯电（EV） | 充电成本、百公里电耗、本月花费 |
| 油电混动车主（示例：丰田 凯美瑞双擎） | 油电混动（HEV） | 油耗、加油开销、每公里成本 |
| 插电混动车主（示例：宋PLUS DM-i） | 插电混动（PHEV） | 电耗 + 油耗双指标、油电成本占比 |
| 燃油车主（示例：宝马 3系 325Li） | 纯燃油（ICE） | 油耗、油价、保养周期 |
| 多车家庭 / 公司用车 | 以上混合 | 车辆切换、各车独立账本 |

典型场景：

- **充电后**打开 App，点 FAB 记一笔充电费用，回到首页看到本月成本变化。
- **月初复盘**：查看上月花费趋势、开销构成，判断哪类支出偏高。
- **保养前**：首页「下次保养」提示还剩 1,574 km / 约 22 天；临近时变红提醒。
- **换车开**：横滑或点选切换车辆，Hero、能耗、保养、趋势、构成、记录整体切换为该车数据。

### 4.2 字体与字号

Plus Jakarta Sans（数字与拉丁字符），中文使用系统字体（PingFang SC / HarmonyOS Sans / Noto Sans SC）回退。

| 样式 | 字号 / 行高 / 字重 | 用途 |
| --- | --- | --- |
| display-hero | 38 / 44 / 800，字距 -0.03em | Hero 卡核心 KPI 数字 |
| headline-lg | 26 / 34 / 700，字距 -0.02em | 卡片金额、保养里程 |
| headline-md | 20 / 28 / 700 | 页面标题「车小记」 |
| headline-sm | 16 / 22 / 700 | 卡片标题、金额、车辆名 |
| body-lg | 15 / 22 / 500 | 列表标题 |
| body-md | 13 / 18 / 500 | 单位、辅助说明 |
| body-sm | 11 / 16 / 400 | 日期、备注、图例 |
| label-lg / md / sm | 13 / 11 / 10，600–700 | 按钮、标签、Tab 文案 |

货币符号 `¥`、单位 `/km`、`kWh/百公里`、`km 后` 字号约为数值的 55%–65%，使用 500–600 字重。能耗卡主数值 24px / 700，副能耗 14px / 700（橙色）。

### 4.3 圆角、间距、阴影

- 页面外边距 16px，模块纵向间距 20px（Hero 上下 16–20px），卡片内边距 16px。
- 卡片圆角 16px；车辆卡 16px；图标容器 8–16px；标签/胶囊全圆角；分类色标签 6px。
- 卡片阴影：`0 8px 24px -4px rgba(15,23,42,.04)`，内描边 `1px rgba(255,255,255,.8)`。
- 车辆选中卡：`2px #00C48C` 边框 + `ring 2px rgba(0,196,140,.2)` + `0 8px 24px -4px rgba(0,196,140,.25)`；未选中卡 85% 不透明度、1px 浅灰边框。
- Hero 卡：渐变 `#00C48C → #05B380 → #0A8C66`，外阴影 `0 12px 32px rgba(0,196,140,.22)`，叠加有机波浪纹理与光晕。
- FAB：56×56，渐变绿，外发光 `0 12px 24px -4px rgba(0,196,140,.45)`，白边环 4px。
- 底部导航：白色 90% + 20px 背景模糊，顶部圆角 16px，上边阴影。

### 4.4 动效

| 场景 | 效果 |
| --- | --- |
| 车辆选中态切换 | 边框 / 阴影 / 勾选徽标 200–300ms 过渡 |
| 车辆卡横向自动居中 | 切换后平滑滚动到卡片居中（`snap-center`） |
| 仪表盘数据联动 | 内容整体先淡出至 35% + 下移 3px + 缩放 0.995（约 150–220ms），数值替换后淡入恢复 |
| 环形图 | 弧长与偏移 500ms 缓动 |
| 趋势曲线 | 路径切换 500ms 过渡；范围切换 200ms 淡入 |
| 数字 | 同车数据刷新时可做 300ms 数字滚动；首次进入不做 |

### 4.5 适配

- 移动端竖屏，内容区最大宽度 448px 居中。
- 覆盖 375–430pt 宽度；左右安全区 + 底部安全区。
- 明暗两套主题；深色稿需按新版联动样式同步。
- 页面整体纵向滚动；顶部栏 sticky 半透明模糊；底部导航 fixed。
- 内容区底部预留 112px，避免被导航栏与 FAB 遮挡。

## 6. 模块需求

### 6.1 顶部栏

**展示内容**

- 左侧圆形头像（40×40，白色描边 + 阴影），右下角 12×12 绿色在线/状态点。
- 头像右侧两行：第一行问候语（11px，次要色），第二行页面标题「车小记」（20px，700）。
- 右侧操作胶囊（白底 80% + 轻阴影 + 白描边），内含 3 个 32×32 圆形图标按钮：
  - 月亮：深色 / 浅色模式切换。
  - 调色盘：主题色 / 皮肤切换（P2）。
  - 铃铛：消息中心；有未读时右上角 6×6 红点（`#BA1A1A`）。

**交互与规则**

- 头像点击 → 「我的」页；未登录时显示默认头像，点击 → 登录页。
- 问候语按本地时间：05:00–10:59 早上好；11:00–12:59 中午好；13:00–17:59 下午好；18:00–22:59 晚上好；23:00–04:59 夜深了。昵称取用户资料，过长省略，最多 8 个字符。
- 顶部栏使用页面底色 80% + 高斯模糊，滚动时不改变高度；状态栏文字颜色随明暗主题切换。
- 通知红点仅表示「有未读」，进入消息中心后清除；消息中心本期是否实现见 Q8。

**验收**

- [ ] 滚动时顶部栏固定在状态栏下方，背景模糊可见内容穿过。
- [ ] 切换深色模式后顶部栏、图标、文字同步变色，无白块闪烁。
- [ ] 未读数 > 0 时显示红点，= 0 时隐藏。
- [ ] 标题显示为「车小记」。

### 6.2 我的车辆

**展示内容**

- 区块标题「我的车辆」（16px / 700）+ 绿色波浪装饰线（仅装饰，24×8 SVG）。
- 标题右侧分页指示器：圆角胶囊底，当前页为 16×6 绿色长条，其余为 6×6 灰点；数量 = 车辆数（最多显示 5 个，超过时显示省略）。
- 最右侧「管理车辆」文字按钮 + 调节图标（tune），绿字浅绿底胶囊。
- 横向滚动车辆卡（snap 滚动，卡宽 192px，间距 12px），支持四类动力：

| 动力 | 卡内图标 | 图标底色 | 里程胶囊文案 | 右上角次要标签（未选中时） |
| --- | --- | --- | --- | --- |
| 纯电 EV | 闪电 | 浅绿 | 纯电 · 18,426 km | 无 / 可选「纯电」 |
| 油电混动 HEV | 油枪 | 浅橙 | 油电混动 · 46,210 km | 油电双模（橙） |
| 插电混动 PHEV | 充电桩 | 浅蓝 | 插电混动 · 31,520 km | 绿牌插混（蓝） |
| 纯燃油 ICE | 油枪 | 浅琥珀 | 纯燃油 · 58,940 km | 95号汽油（灰） |

- 每张卡：车辆图标（28×28 圆角方块）、右上角状态徽标、车辆名（16px / 700，单行省略）、车牌（11px 次要色）、动力与里程胶囊（含 6px 同色圆点）、右下角 14×14 模糊光斑。
- 选中卡：2px 品牌绿边框 + 绿色外发光 + 右上角绿色勾选徽标；次要标签隐藏；不透明度 100%。
- 未选中卡：1px 浅灰边框、85% 不透明度，hover / 按下恢复到 100%；右上角显示次要标签。
- 末尾「添加车辆」卡：宽 80px，虚线边框，圆形 + 号 + 10px 文案。

**交互与规则**

- 点击车辆卡 → 选中该车：
  1. 卡片选中态与分页指示器同步（≤300ms）；
  2. 该卡自动平滑滚动到可视区域居中；
  3. Hero、双指标、趋势、构成、最近记录整体切换为该车数据（过渡动效见 §4.4）；
  4. 若数据未缓存，各模块进入骨架屏，数据到齐后整体替换。
- 切换时取消上一车辆未完成的请求，避免响应乱序覆盖。
- 横向滑动：滚动结束后以最近吸附卡为准更新指示器；**滑动本身不改变选中车辆**（点击才切换）。
- 「管理车辆」→ 车辆管理页；「添加车辆」卡 → 添加车辆向导。

**展示内容**

**状态**

- 加载中：渐变卡显示骨架（数值位置灰白条）。

**验收**

- [ ] Hero 的「本月花费」= 开销构成「合计」= 本月记账总额（自然月，仅该车）。
- [ ] 上涨时环比胶囊为玫红底 + 上箭头，下降时为白底 + 下箭头。

## 7. 数据口径与格式化

### 7.1 指标定义

| 指标 | 公式 | 边界 |
| --- | --- | --- |
| 本月花费 | Σ 当月该车记账金额（自然月） | 无记录 → 0 |
| 本月里程 | 当月里程表读数 max − min；否则 Σ 记账里程 | < 0 → 0；无 → 0 |
| 综合每公里成本 | 本月花费 ÷ 本月里程 | 无记录 → `¥0.00`；有记录但里程 = 0 → 显示「—」；保留 2 位 |
| 能源成本/km | (充电 + 加油) ÷ 本月里程 | 同上 |
| 平均电耗 | 当月充电量 ÷ 本月里程 × 100 | 纯电 / 插混；保留 1 位 |
| 平均油耗 | 当月加油量 ÷ 本月里程 × 100 | 燃油 / 混动 / 插混；保留 1 位 |
| 保养剩余里程 | 保养周期 −（当前里程 − 上次保养里程） | 可为负（超期） |
| 保养剩余天数 | 剩余里程 ÷ 近 30 日日均里程 | 日均为 0 → 不显示 |
| 保养进度 | 已行驶里程 ÷ 保养周期 × 100 | 封顶 100%；> 80% 警示 |
| 分类占比 | 分类金额 ÷ 总金额 × 100 | 四舍五入整数 |
| 趋势合计 | Σ 所选区间该车记账金额 | 与 Hero 自然月口径独立 |
| 趋势环比 | (本期 − 上期) ÷ 上期 × 100 | 上期为 0 → 显示「—」 |
| 充电每公里成本 | 单笔金额 ÷ 里程增量 | 增量 ≤ 0 → 不显示 |
| 加油单价 | 单笔金额 ÷ 加油升数 | 升数 ≤ 0 → 不显示 |

### 7.2 时间口径

- **Hero、开销构成、最近记录**：自然月（每月 1 日 00:00 至月末），按设备本地时区。
- **花费趋势**：用户所选滚动区间，默认「近 30 天（含今天）」。
- 两套口径**刻意不同**：Hero 回答「这个月花了多少」，趋势回答「最近一段时间怎么花的」，数值不一致属预期，不视为数据错误。
- 最近记录不限制在自然月内，按全部记录倒序取最近 N 条（设计稿示例包含上月记录）。
- 时区固定设备本地时区；跨时区旅行不做特殊处理。

### 7.3 格式化

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 聚合金额 | 千分位，四舍五入取整 | `¥1,286` |
| 明细金额 | 千分位，保留 2 位 | `-¥51.10` |
| 每公里成本 | 保留 2 位 | `¥0.60 /km` |
| 单价 | 保留 2 位 + 单位 | `¥8.16/L`、`¥0.17/km` |
| 里程 | 千分位整数 | `18,426 km` |
| 能耗 | 1 位小数 | `14.8 kWh/百公里`、`4.5 L/百公里` |
| 百分比 | 整数 + `%`，下降带 `-` | `-8.2%`、`30%` |
| 日期 | 今天 / 昨天 / 前天 / M月D日 / YYYY年M月D日 | `今天 08:42` |
| 空值 | 统一 `—` | `¥—` |

## 9. 全局状态与异常

| 状态 | 表现 |
| --- | --- |
| 首次加载 | 各模块独立骨架屏；顶部栏、底部导航立即可用 |
| 切换车辆 | 卡片选中态立即变化；仪表盘内容淡出 → 骨架 / 新数据 → 淡入 |
| 下拉刷新 | 整页刷新当前车辆；刷新失败保留旧数据 + Toast「刷新失败」 |
| 模块级失败 | 该模块显示「加载失败，点击重试」，其他模块正常 |
| 无车辆 | 车辆区空状态 + 其余模块显示引导，不请求业务接口 |
| 无当月数据 | 各卡显示 0 / 空状态，FAB 高亮引导记账 |
| 登录过期 | 拦截并跳登录页，登录后回到首页并恢复上次车辆 |
| 车辆已删除 / 无权限 | 自动切换到默认车，Toast 提示 |
| 网络慢（> 1s） | 骨架屏保持，不显示 loading 弹窗 |
| 断网 | 展示缓存 + 顶部条「当前为离线数据」 |
| 车辆切换请求失败 | 保留切换后的车辆选中态，模块显示重试；不回滚选中车辆 |

## 10. 非功能需求

- **性能**：4G 冷启动首屏可交互 ≤ 2s；首页数据请求 ≤ 1.5s（P90）；车辆切换后的数据渲染 ≤ 400ms（有缓存时 ≤ 100ms）；滚动 60fps；图表使用 GPU 绘制，避免每帧重建整个页面。
- **包体**：图表库选型优先轻量（fl_chart 或自绘 CustomPainter）；字体按需子集化。
- **主题**：浅色 + 深色，跟随系统或用户设置；切换即时生效，无需重启。深色版需覆盖四类动力车辆卡与双能耗卡。
- **无障碍**：金额卡片整体可朗读（如「本月综合每公里成本 0.60 元」）；颜色不作为唯一区分手段（分类、动力均有文字）；支持系统字体缩放至 1.3 倍不截断关键金额。
- **本地化**：本期仅中文、人民币、公里、kWh、L；文案集中管理，为后续多语言预留。
- **安全与隐私**：车辆、账单按用户隔离；日志与埋点不得上传车牌、地点等敏感明文。
- **稳定性**：所有模块可独立降级，任何单个接口失败不导致白屏；车辆切换的并发请求需可取消。
