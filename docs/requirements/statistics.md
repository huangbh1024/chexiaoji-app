## 1. 背景与目标

首页回答「**这辆车现在怎么样**」，账单页回答「**每一笔都记了什么**」，统计页回答：

1. 在选定时间范围内，这辆车（或全部车辆）**一共花了多少、每公里多少钱**？
2. 钱花在**哪些类别**上，占比如何？
3. 花销的**走势**是什么样的，高峰出现在哪一天 / 哪一类？
4. 能耗水平和保养节奏是否**健康**？

设计目标：

- 一屏内先看到「每公里成本 + 关键构成」，向下滚动完成从**总览 → 指标 → 走势 → 构成 → 明细**的分析闭环。
- 同一屏内的所有数字都标注了口径（周期名 / 区间名），用户不会看到两个互相矛盾却没有说明的「合计」。
- 车辆与周期切换在 1 次点击内完成，且所有模块同步联动；趋势粒度可单独调整，不影响其他模块。
- 复用首页 / 账单页的视觉与组件，统计页不产生第二套卡片、图表与颜色规范。

## 2. 用户与典型场景

| 用户 | 关注点 | 本页价值 |
| --- | --- | --- |
| 纯电车主 | 百公里电耗、充电占比、每公里成本 | 判断本月充电开销是否异常 |
| 燃油车主 | 油耗、油价、保养支出 | 对比上月用车成本，识别大额保养 |
| 插混车主 | 电耗 + 油耗双指标、油电占比 | 判断油电使用结构是否合理 |
| 多车家庭 / 公司用车 | 各车对比、车队总开销 | 切到「全部车辆」看合并核算，再下钻到单车 |
| 记账新用户 | 数据是否可信 | 空态与口径说明，引导先记第一笔 |

典型场景：

- **月初复盘**：切到「月度」，看本月总开销、每公里成本与上月对比，再看向开销构成，确认哪类支出最高。
- **加油 / 充电后**：切到「周」看本周成本变化，确认最近一次补能是否拉高了每公里成本。
- **保养前**：查看「下次建议保养」剩余里程与预计天数；超过 80% 时进入警示态。
- **年度总结**：切到「年度」，看全年走势高峰与分类构成，再导出月度报表。
- **多车管理**：切到「全部车辆」，看车队总开销与最紧迫的保养提醒，再点选具体车辆下钻。
- **异常排查**：在趋势卡里切到「7 天」，确认某天的高峰是哪一类开销。

### 4.2 字体与字号

Plus Jakarta Sans（数字与拉丁字符），中文回退 PingFang SC / HarmonyOS Sans / Noto Sans SC。

| 样式 | 字号 / 行高 / 字重 | 用途 |
| --- | --- | --- |
| display-hero | 38 / 44 / 800，字距 -0.03em | Hero 每公里成本 |
| headline-lg | 26 / 34 / 700 | 能耗 / 保养主数值 |
| headline-md | 20 / 28 / 700 | 顶部标题、趋势合计、图表卡片标题 |
| headline-sm | 16 / 22 / 700 | 卡片标题、图例金额、记录金额 |
| body-md | 13 / 18 / 500 | 图例分类名、辅助说明 |
| body-sm | 11 / 16 / 400 | 单位、日期、图例、坐标轴 |
| label-md | 11 / 14 / 600 | 周期胶囊、车辆胶囊、颗粒度切换 |
| label-sm | 10 / 12 / 700 | 评级标签、图表提示、百分比 |

数值排版：

- Hero：`¥` 16px/600，整数与小数 38px/800，`/km` 13px/500，均基线对齐；数字整体占用不超过一行。
- 趋势合计：`¥1,286` 20px/800；环比文案 11px/700。
- 环形图中心：标签 10px/400，金额 16px/700。
- 坐标轴：9px/400（与设计稿一致）。

### 4.3 圆角、间距、阴影

- 页面外边距 16px；模块纵向间距 16px；内容最大宽度 448px 居中。
- 卡片圆角 **16px**（与首页一致；设计稿的 32px 按全站现状收敛），Hero 同 16px；卡片内边距 20px；双指标卡内边距 16px。
- 周期筛选托盘：全圆角、内边距 4px、白底 + 轻阴影；选中胶囊使用 `onSurface` 底 + `surface` 文字。
- 车辆胶囊：全圆角，白底 95%，1px `#E5EEFF` 描边，轻阴影。
- 卡片阴影：`0 8px 24px -4px rgba(15,23,42,.04)` + `0 2px 6px -1px rgba(15,23,42,.02)`，1px 白色内描边。
- Hero 阴影：`0 16px 36px -8px rgba(0,196,140,.28)`。
- FAB：56×56，绿底白 `+`，白色 4px 边环，阴影 `0 10px 24px -2px rgba(0,196,140,.45)`。
- 底部导航：白 90% + 20px 背景模糊，顶部圆角 48px（沿用 `AppBottomNav`）。

### 4.4 动效

| 场景 | 效果 |
| --- | --- |
| 周期切换 | Hero / 双指标 / 构成 / 记录 150ms 淡出；数据替换后 200ms 淡入；趋势卡按新默认粒度同步切换 |
| 车辆切换 | 弹层收起 250ms；页面内容整体淡出 / 淡入；选中态 200ms |
| 趋势粒度切换 | 曲线路径 400ms 插值；合计数字随卡片淡入；Y 轴刻度同步更新 |
| 环形图 | 扇区扫入 500ms（首帧不做，切换时做） |
| 保养进度环 | 从 0 到目标值 600ms 缓动 |
| 数值变化 | 不做逐位滚动（避免与淡入冲突） |
| 下拉刷新 | `RefreshIndicator`，主色 |
| 图表点按 | 选中点放大 150ms；提示气泡 120ms 淡入 |

### 4.5 适配

- 竖屏手机，375–430pt；内容区最大 448px。
- 顶部栏 sticky（64px，86% 背景 + 模糊）；底部导航 fixed。
- 内容底部预留 112px + 安全区，避免被导航与 FAB 遮挡。
- 明暗主题均可用；深色稿未提供，按 `AppPalette.dark` 推导并在实现后请设计复核。
- 系统字号放大到 1.3 倍时：Hero 数字允许缩小到 32px；图例、坐标轴不参与放大（避免图表溢出），但金额与标题必须完整显示。

## 6. 模块需求

### 6.1 顶部栏

**展示内容**

- 左侧 40×40 头像（与首页一致，登录后取用户头像；未登录用默认渐变头像 + 姓氏首字）。
- 头像右侧两行：
  - 问候语 11px/400 次要色：早上好 / 中午好 / 下午好 / 晚上好 / 夜深了 + 「，{昵称}」。
  - 标题「数据统计」20px/700 主文字。
- 右侧：
  - 车辆切换胶囊：8px 动力色圆点 + 当前车辆名（11px/700）+ 下箭头；未选具体车时为深绿圆点 +「全部车辆」。
  - 36×36 白色圆形通知按钮 + 红点（有未读时）。
- 顶部栏固定，背景 86% + 20px 模糊；下方内容可透过。

**交互与规则**

## 7. 数据口径与格式化

### 7.1 周期定义

所有周期按设备本地时区计算（接口可传 `tz`，默认 `Asia/Shanghai`）。

| 周期 | 起止 | 标签 | 对比周期 |
| --- | --- | --- | --- |
| 周 | 本周一 00:00:00 – 本周日 23:59:59 | `本周 (6/24–6/30)` / 历史 `6/17–6/23` | 上一周 |
| 月度 | 自然月 1 日 00:00 – 月末 23:59:59 | `2024年6月` | 上一自然月 |
| 半年 | 1/1–6/30 或 7/1–12/31 | `2024上半年` / `2024下半年` | 去年同一半年 |
| 年度 | 1/1–12/31 | `2024年` | 上一自然年 |
| 全部 | 首条记录时间 – 现在 | `累计至今` | 无 |

- 默认周期：月度，锚点为今天所在月份。
- 默认车辆范围：首页当前选中车辆；若无车辆则「全部车辆」。
- 「全部」的累计年限 = (今天 − 首条记录日期) ÷ 365.25，保留 1 位，如 `累计 2.1 年`；不足 1 个月显示 `累计 12 天`。

### 7.2 指标定义

| 指标 | 公式 | 边界 |
| --- | --- | --- |
| 周期总开销 | Σ 周期内该范围记账金额 | 无记录 → 0 |
| 周期行驶 | 里程表读数最大值 − 最小值；不足则 Σ 单笔里程 | < 0 或无法计算 → 0，来源标记 `none` |
| 综合每公里成本 | 总开销 ÷ 行驶里程 | 里程 0 → `—`；保留 2 位 |
| 能源总开销 | Σ 充电 + 加油金额 | 无 → 0 |
| 能源成本 /km | 能源总开销 ÷ 行驶里程 | 里程 0 → `—`；保留 2 位 |
| 平均电耗 | Σ 充电量 ÷ 行驶 × 100 | 无充电 / 里程 0 → `—`；1 位小数 |
| 平均油耗 | Σ 加油升数 ÷ 行驶 × 100 | 无加油 / 里程 0 → `—`；1 位小数 |
| 环比 | (本期 − 上期) ÷ 上期 × 100 | 上期 0 → 无对比；1 位小数 |
| 分类占比 | 分类金额 ÷ 总金额 × 100 | 最大余数法取整，合计 100% |
| 能耗评级 | 与过去 6 个同长度周期均值比较 | 无历史 → `—`；阈值 ±5% |
| 保养进度 | 已行驶 ÷ 保养周期 × 100 | 封顶 100%；> 80% 警示 |
| 保养剩余天数 | 剩余里程 ÷ 近 30 天日均里程 | 日均 0 → 不显示 |
| 趋势桶合计 | 桶内能源 + 其他 | 无记录桶为 0 |
| 趋势窗口合计 | Σ 全部桶 | 与 Hero 周期总额独立 |

### 7.3 趋势分桶

| 粒度 | 起点 | 桶 | 上一窗口 |
| --- | --- | --- | --- |
| 7天 | 今天 − 6 天 00:00 | 每天 | 再往前 7 天 |
| 30天 | 今天 − 29 天 00:00 | 每天 | 再往前 30 天 |
| 半年 | 当月往前 5 个月的 1 日 | 每月 | 再往前 6 个月 |
| 1年 | 当月往前 11 个月的 1 日 | 每月 | 再往前 12 个月 |

- X 轴固定 7 个标签（首、尾必含），中间等距取样。
- Y 轴刻度：起点 0，上限取窗口单桶最大值向上取整到「1 / 2 / 5 × 10^n」，再均分 3 段；全 0 时上限为 `¥100`。
- 峰值桶 = 桶合计最大者；并列时取时间较近者。
- 提示文案：`{M/D 或 M月} {主分类} {金额}`；主分类取桶内金额最大的分类，无记录桶不显示提示。

### 7.4 构成与百分比

- 分类金额来自周期内记录，按金额降序。
- 分类数 > 6 时保留前 5 + 「其他」；单类 < 2% 并入「其他」。
- 百分比使用最大余数法：先取整，再把差值按小数部分从大到小补到对应分类，确保合计 = 100%。
- 环形图角度 = 百分比 × 3.6°，扇区间距 2px，起始角 -90°。
- 设计稿示例中 `37+30+13+10+7 = 97%` 且金额合计 `¥1,256 ≠ ¥1,286`，属示例错误；实现必须满足两项一致性。

### 7.5 格式化

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 聚合金额 | 千分位、取整 | `¥1,286` |
| 明细金额 | 千分位、2 位小数、支出带负号 | `-¥51.10` |
| 每公里成本 | 2 位小数 | `¥0.60 /km` |
| 能耗 | 1 位小数 + 单位 | `14.8 kWh/百公里`、`7.6 L/百公里` |
| 百分比 | 整数 + `%`；环比带符号 | `37%`、`-8.2%` |
| 里程 | 千分位整数 + `km` | `2,140 km` |
| 日期 | 今天 / 昨天 / 前天 / M月D日 / YYYY年M月D日 | `今天 08:42` |
| 空值 | 统一 `—` | `¥—`、`— kWh/百公里` |
| 累计年限 | 1 位小数 + 年 | `累计 2.1 年` |

| 状态 | 表现 |
| --- | --- |

## 10. 非功能需求

- **性能**：统计 Tab 首次进入 ≤ 1s 可交互；周期 / 车辆切换 ≤ 500ms（有缓存 ≤ 120ms）；图表滚动与点按 60fps；图表局部重绘，不重建整页。
- **数据量**：「全部」范围可能跨 24 个月以上、上千条记录；聚合优先服务端完成，客户端只做展示；Mock 阶段在后台 isolate 或一次性内存聚合，避免主线程卡顿。
- **主题**：浅 / 深色完整覆盖；Hero 渐变、环形图、网格线、骨架屏均在深色下可读；不使用硬编码颜色（分类色除外）。
- **无障碍**：
  - Hero 卡整体语义为「综合每公里成本 0.60 元，较上月下降 8.2%」。
  - 环形图提供文字摘要：「保养 480 元，占 37%」等。
  - 趋势图提供摘要：「近 30 天花费 1,286 元，峰值 6 月 15 日保养 480 元」。
  - 颜色不是唯一区分手段：图例有文字，评级有文案。
  - 点击区域 ≥ 44×44。
- **本地化**：中文、人民币、公里、kWh、L；文案集中管理。
- **安全与隐私**：车牌、地点不明文上报埋点；统计接口按用户与车辆权限隔离；全部车辆不泄露无权车辆。
- **稳定性**：任一模块失败不白屏；图表空数据不崩溃；日期计算跨月 / 跨年 / 闰年正确。
