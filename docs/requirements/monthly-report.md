## 1. 背景与目标

账单页回答「**每一笔都记了什么**」，本页回答「**这个月整体花了多少、能不能拿出去报销或分享**」。

用户月底要做三件事：核对、归档、把凭证交给公司或家人。当前账单页只能浏览和筛选，导出仍是占位提示。本页把「月度汇总 + 可打印凭证 + 导出配置」收在一屏，让用户：

1. 一眼看到这个月（或某辆车）的**总开销、每公里成本、行驶里程、能耗**；
2. 在手机里直接预览**接近 A4 纸的成品报表**，所见即所得；
3. 选择 PDF / CSV / 长图，勾选是否包含能耗分析、是否隐藏车牌，**一次点击导出或打印**。

设计目标：

- **预览即成品**：屏幕上的 A4 预览与导出的 PDF 使用同一份数据、同一套信息层级，不出现「预览有、导出没有」；
- **三步完成**：进入页面 → 确认月份与车辆 → 点「立即导出」，不要求先填表；
- **报销友好**：金额、分类、里程、能耗、生成时间、单号齐全，PDF 中文字可选中、可打印；
- **隐私可控**：车牌脱敏开关在预览与所有导出格式中同步生效；
- **跨页一致**：金额、分类、车辆、环比口径与账单页、首页完全一致，同一月份的数字必须对得上。

## 2. 用户与典型场景

| 用户 | 场景 | 关注点 |
| --- | --- | --- |
| 上班族 | 公司按月报销通勤 / 油费 | PDF 是否正规、金额与分类是否清晰、能否打印 |
| 一人多车 | 分别导出每辆车的月报 | 车辆切换、单车报表、里程与能耗 |
| 纯电车主 | 记录月度充电成本 | kWh、百公里电耗、每公里成本 |
| 燃油 / 混动车主 | 核对油费与保养 | 升数、百公里油耗、保养占比 |
| 家庭共用 | 发给家人对账 | 长图分享、隐私脱敏 |
| 会计 / 财务 | 导入 Excel | CSV 字段完整、中文不乱码、金额可计算 |

典型场景：

- **月底报销**：从账单页点导出 → 默认当前月、全部车辆 → 选 PDF → 打开「隐藏车牌」→ 立即导出 → 系统分享到微信 / 邮件 / 打印。
- **单车核算**：进入本页，点「比亚迪 汉 EV」chip，预览与数字立即切换为该车，再导出。
- **历史补档**：点「切换月份」选 3 月，报表状态显示「已出账」，导出归档。
- **核对数据**：发现报表总额与账单页不一致时，回到账单页按同月同车核对（两页必须同口径）。
- **社交分享**：选择「长图海报」（P1），生成适合车友圈的高清长图。

### 3.2 本期不做

- 在线编辑账目、补录、删除（仍在账单 / 记账页完成）。
- 财务报表审计、发票验真、税务合规认证。
- 真正的「财务专用章」或电子签章；设计稿中的戳记为**装饰性元素**，不具备法律效力（见 §13 Q4）。
- 多用户 / 家庭账本的联合报表。
- 服务端生成并长期托管报表文件（本期在客户端生成，随用随删）。
- 报表模板自定义（配色、Logo、字段顺序）。

### 4.3 圆角、间距、阴影

- 页面外边距 16px；顶栏与范围条间距 8px；范围条与预览区间距 20px；预览区与导出区间距 28px。
- A4 预览纸圆角 **24px**、内边距 20px、1px 白色描边，阴影 `0 16px 36px -8px rgba(11,28,48,.08), 0 4px 12px -2px rgba(11,28,48,.04)`。
- 报表内车辆信息条圆角 12px、内边距 12px。
- KPI 小卡圆角 16px、内边距 10px、1px `#E5EEFF` 60% 描边。
- 图表卡圆角 16px、内边距 12px。
- 导出格式卡圆角 16px、内边距 12px；选中态 2px `#00C48C` 描边 + 右上角 20×20 勾选徽标。
- 配置卡圆角 16px、内边距 16px，行间距 12px，分隔线 1px `#EFF4FF`。
- 底部操作栏全宽、白色 90% + 24px 模糊、上阴影 `0 -4px 24px rgba(15,23,42,.06)`，上内边距 12px、下内边距 24px + 安全区。
- 按钮高 48px；次按钮圆角全圆、水平内边距 16px；主按钮圆角全圆、水平内边距 24px。

### 4.4 动效

| 场景 | 效果 |
| --- | --- |
| 进入页面 | 标准右进左出 250ms；预览纸淡入 200ms |
| 切换月份 / 车辆 | 预览内容淡出 120ms → 骨架 → 新数据淡入 200ms；按钮与范围条保持可点 |
| 切换导出格式 | 卡片 150ms 边框 / 阴影 / 缩放过渡；CTA 文案立即更新 |
| 勾选开关 | 20×20 勾选框 120ms 缩放 + 主色填充；预览对应区块 150ms 显隐 |
| 导出中 | CTA 内图标替换为 18px 转圈，按钮禁用；进度文案按阶段更新 |
| 全屏预览 | 250ms 淡入；关闭 200ms 淡出 |
| 双指缩放 | 跟手，无惯性动画；双击 200ms 在 1× / 2× 间切换 |

遵循系统「减少动态效果」：关闭脉冲圆点、页面淡入与缩放动画。

### 4.5 适配

- 竖屏；内容区最大宽度 448px 居中。
- 覆盖 375–430pt；左右与底部安全区适配。
- 顶栏 sticky（64px，背景 86% + 16px 模糊）；底部操作栏 fixed。
- 页面内容底部预留 128px + 安全区，避免被操作栏遮挡。
- A4 预览按 210:297 固定比例，宽度撑满内容区，高度按比例计算；小屏不横向滚动。
- 明暗两套主题；深色稿未出，按首页 `AppPalette.dark` 推导，导出 PDF 固定浅色（纸张不随主题变化）。

## 6. 模块需求

### 6.1 顶部栏

**展示内容**

- 左侧 40×40 白色圆形返回按钮（轻阴影，`arrow_back` 20px）。
- 标题「月度报表与导出」（16 / 700）；副标题「核对用车成本并生成凭证文档」（11 / 400，次要色）。
- 右侧 40×40 白色圆形按钮两个：打印（`print`）、分享（`share`）；按下时图标变主色并缩放 0.95。

**交互与规则**

- 返回：关闭本页回到账单页；账单页的月份、车辆、分类筛选保持不变。
- 打印：按当前范围与开关生成 PDF，调用系统打印服务；生成中按钮内显示 18px 转圈并禁用重复点击。
- 分享：按当前范围与开关生成 PDF，打开系统分享面板；生成中同样禁用。
- 打印 / 分享与底部 CTA 共用同一份 PDF 生成逻辑与文件名。
- 当前月无任何记录时，打印 / 分享仍可点，但提示「本月暂无可导出的记录」并中止。

**CSV 内容**

- 记录按发生时间正序（从月初到月末），便于逐行核对；表头冻结不做（CSV 无样式）。

**打印**

- 使用系统打印服务，直接提交当前 PDF；打印预览中的纸张、边距、缩放由系统控制。

## 7. 数据口径与格式化

### 7.1 指标定义

| 指标 | 公式 | 边界 |
| --- | --- | --- |
| 报表总额 | Σ 当月该车辆范围全部记录金额（支出正、退款负） | 无记录 → 0 |
| 笔数 | 当月该车辆范围记录条数 | — |
| 本月行驶 | max(月内里程表读数) − min(月内里程表读数) | 少于 2 条读数 → 若记录含单笔行驶距离则求和；否则 0 / `—` |
| 综合每公里 | 报表总额 ÷ 本月行驶 | 里程 0 → `—`；保留 2 位小数 |
| 充电量 | Σ 充电记录的 kWh | 无 → 0 |
| 加油量 | Σ 加油记录的 L | 无 → 0 |
| 百公里电耗 | 充电量 ÷ 行驶里程 × 100 | 里程 0 → `—`；1 位小数 |
| 百公里油耗 | 加油量 ÷ 行驶里程 × 100 | 里程 0 → `—`；1 位小数 |
| 环比 |（本月总额 − 上月同范围总额）÷ 上月总额 × 100% | 上月 0 / 无数据 → 「较上月 —」 |
| 分类分组金额 | Σ 组内分类记录金额 | 可为负（退款） |
| 分类百分比 | 分组金额 ÷ 报表总额 × 100%，最大余数修正 | 总额 ≤ 0 → `—` |
| 当月天数 | 当月自然日天数（28–31） | 用于「公里 · N天」 |
| 累计总里程 | 单车 = 车辆 `odometerKm`；全部车辆 = Σ `odometerKm` | 车辆缺失 → `—` |

### 7.2 报表状态与单号

| 状态 | 条件 | 徽标 | 日期文案 |
| --- | --- | --- | --- |
| 记录中 | 范围月份 = 当前自然月 | 「记录中」橙 | 「数据截至 MM-DD HH:mm」 |
| 已出账 | 范围月份 < 当前自然月 | 「已出账」蓝 | 「YYYY-MM-DD 结算」（月末最后一天） |

- 单号格式 `RP-{YYYYMM}-{4 位序号}`；同一用户 + 月份 + 车辆范围在会话内稳定。
- 单号仅用于报表展示与归档识别，不作为财务凭证编号；服务端返回时以服务端为准。
- 未来月份不可选，不产生报表。

### 7.3 分类合并规则

| 报表分组 | 包含 `ExpenseCategory` | 图例文案 |
| --- | --- | --- |
| 充电动能 | `charging` | 充电动能 |
| 燃油加注 | `fuel` | 燃油加注 |
| 常规保养 | `maintenance` | 常规保养 |
| 临停泊车 | `parking` | 临停泊车 |
| 高速通行 | `toll` | 高速通行 |
| 洗车及其他 | `carWash` + `other` | 洗车及其他 |

- 分组固定 6 项，顺序固定；金额为 0 的分组省略。
- 合并后的「洗车及其他」金额 = 洗车 + 其他（含保险）；百分比按合并后计算。
- 分类筛选不作用于报表；报表始终统计全部分类。

### 7.4 隐私脱敏

- 车牌脱敏格式：保留省份、城市字母与分隔点后的首位，其余替换为 `*`，且总长度与原车牌一致。
  - `粤B·D82K6` → `粤B·D****`
  - `粤B·88K32` → `粤B·8****`
  - 无分隔点的车牌：保留前 2 位，其余 `*`。
  - 长度 ≤ 3：全部 `*`。
- 脱敏作用于：预览车辆信息条、PDF 车辆信息条、CSV「车牌」列。
- 不作用于：报表标题、车辆名（如「比亚迪 汉 EV」）、备注自由文本、文件名。
- 开关关闭时输出完整车牌。

### 7.5 格式化

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 总开销 | 千分位、取整、`¥` | `¥1,286` |
| 每公里成本 | `¥` + 2 位小数 | `¥0.60` |
| 里程（KPI） | 千分位整数 | `2,140` |
| 里程（车辆条） | 千分位整数 + `km` | `18,426 km` |
| 电量 | 1 位小数 + `kWh` | `316.7 kWh` |
| 油耗 | 1 位小数 + `L` | `120.5 L` |
| 百公里能耗 | 1 位小数 + 单位 | `14.8 kWh/100km`、`6.2 L/100km` |
| 百分比 | 整数 + `%` | `37%` |
| 环比 | 带符号 1 位小数 + `%` | `-8.2%`、`+4.2%` |
| 月份 | `YYYY年M月` | `2024年6月` |
| 结算日期 | `YYYY-MM-DD` | `2024-06-30` |
| 数据截止 | `MM-DD HH:mm` | `11-14 18:30` |
| 单号 | `RP-YYYYMM-XXXX` | `RP-202406-8821` |
| 空值 | 统一 `—` | `—` |

### 7.6 CSV 字段

| 列 | 类型 | 说明 |
| --- | --- | --- |
| 日期 | `YYYY-MM-DD` | 本地时区发生日期 |
| 时间 | `HH:mm` | 无时刻记录为空 |
| 分类 | 文本 | 充电 / 加油 / 保养 / 停车 / 过路费 / 洗车 / 保险其他 |

| 车牌 | 文本 | 隐私开关开启时脱敏 |
| 标题 | 文本 | 商家 / 站点 / 项目名 |
| 金额(元) | 数值 | 带符号两位小数，支出正、退款负 |
| 电量(kWh) | 数值 | 充电记录有值，否则空 |

## 10. 非功能需求

- **性能**：进入页面 ≤ 800ms 可交互（有缓存 ≤ 200ms）；切换范围首屏 ≤ 500ms；PDF 生成 ≤ 800ms（P90，单页）；CSV 3000 条 ≤ 1.5s；预览滚动与缩放 60fps。
- **内存**：报表聚合结果按 `month + vehicleId` 缓存，最多保留 10 份；临时文件在分享后由系统管理，应用启动清理 24 小时前的文件。
- **稳定性**：导出任务加锁，禁止并发；失败不产生空文件；过期响应不覆盖新数据；任一模块失败不白屏。
- **主题**：页面浅色 + 深色；A4 纸张与所有导出格式固定浅色，保证打印与分享一致。
- **无障碍**：
  - 预览纸整体朗读为一句摘要（「2024年6月，全部车辆，总开销1286元，行驶2140公里，6笔记录」）；
  - 金额读作「元」，百分比读作「百分之」；
  - 开关提供 `checked` 语义与完整说明；
  - 格式卡提供 `selected` 语义；
  - 所有可点区域 ≥ 44×44；字号放大 1.3× 布局不破；
  - 缩放手势提供「全屏全貌」等价入口。
- **本地化**：本期仅中文、人民币、公里、kWh、L；文案集中管理。
- **隐私**：车牌、地点、商家名不进日志与埋点明文；临时文件不上传；分享由用户主动触发。
- **安全**：CSV 公式注入防护；文件名过滤非法字符；不执行外部传入的导出参数。
