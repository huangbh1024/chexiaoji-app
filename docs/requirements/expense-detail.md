## 1. 背景与目标

账单页回答「每一笔都记了什么」，但一条记录的完整信息——支付渠道、精确时间、所属车辆、备注与标签、状态——在列表卡片里放不下。当前点击记录卡只弹「账单详情待接入」，用户无法核对一笔开销，也无法补备注、改标签或删掉误记的一笔。

本页把「**一笔开销的完整凭证**」收在一屏：顶部是金额与状态，其下依次是车辆、结算信息、标签与备注，底部固定「再记一笔 / 编辑此笔账单」。用户进入后 3 秒内能确认「这笔钱花在哪、什么时候、用什么付的、记在哪辆车上」，并能就地完成备注、标签、分享与删除。

设计目标：

- **一眼确认金额**：首屏中心是带符号的金额与状态，标题、分类徽标、时间围绕金额排布，不做信息堆叠。
- **通用而不雷同**：充电、加油、保养、洗车、停车、过路费共用同一结构，只换图标、徽标与语义色，新增分类零页面成本。
- **可维护的凭证**：备注与标签可随时补充，修改即时生效，返回账单后数字不变但内容同步。
- **操作闭环**：删除有确认、分享有内容、编辑有入口，不让按钮成为死路。
- **跨页一致**：金额、分类、时间、车辆与账单页、首页、月度报表同源，避免「详情 51.10、列表 51.00」。

非目标：

- 不在本页做整笔账单编辑（分类、金额、车辆改绑）——归记账 / 编辑页。
- 不在本页做分类专属的深度分析（每公里成本趋势、能耗曲线）——归统计页与 P1 指标格。
- 不提供发票 / 图片凭证管理（P2）。

## 2. 用户与典型场景

| 用户 | 场景 | 关注点 |
| --- | --- | --- |
| 通勤纯电车主 | 月底核对充电开销，确认某次快充的金额、站点与时间 | 金额、站点名、支付渠道、时间 |
| 混动 / 燃油车主 | 出差加油后把凭证分享给同行人 / 报销群 | 分享内容、车牌是否暴露、金额与油量 |
| 家庭多车用户 | 确认这笔保养记在哪辆车上，里程是多少 | 车辆名称、车牌、记账时里程 |
| 健忘型用户 | 三天后补一句「周五午休顺道补电」 | 备注编辑、保存反馈 |
| 误记用户 | 把重复记录或错误金额删掉 | 删除入口、二次确认、删除后统计同步 |

关键任务（按优先级）：

1. 确认金额与状态（T1）。
2. 确认车辆与结算信息（T2）。
3. 补 / 改备注和标签（T3）。
4. 分享或复制这笔开销（T4）。
5. 删除误记记录（T5）。
6. 基于这笔记录再记一笔（T6）。

### 4.5 适配

- 基准画布 390 × 844（设计稿 780 × 2272 @2x）。
- 内容最大宽度 448，居中；平板 / 折叠屏不拉伸单行文本。
- 顶部安全区 + 56、底部安全区 + 底部栏高度内边距，内容底部预留 144，避免被操作栏遮挡。
- 系统字号放大到 1.3 倍：卡片可自然增高，金额允许缩小到 28 号，按钮文字不截断。
- 横屏：本期不专门适配，保持竖屏布局并可滚动。

## 7. 数据口径与格式化

### 7.1 字段来源

| 展示项 | 字段 | 规则 |
| --- | --- | --- |
| 标题 | `title` | 商户 / 站点 / 服务名；空则分类名 |
| 分类 | `category` | 枚举 key；决定图标、徽标文案、语义色 |
| 金额 | `amountCents` | 整数分；正数支出、负数退款；展示时支出加 `-` |
| 状态 | `status` | `completed` / `refunded`；与金额正负必须一致 |
| 交易时间 | `occurredAt` | ISO 8601；本地时区展示 |
| 车辆 | `vehicle.name` / `plate` / `powertrain` | 记账时快照；`bound=false` 显示「已解绑」 |
| 里程 | `vehicle.odometerKm`（记账时） | 整数 km；缺失显示「里程未记录」 |
| 支付渠道 | `payment.channel` / `payment.label` | 枚举 + 展示名；缺失「未记录」 |
| 标签 | `tags` | 字符串数组，≤ 8，单个 ≤ 10 字 |
| 备注 | `note` | ≤ 200 字，可空 |

### 7.2 格式化

| 场景 | 规则 | 示例 |
| --- | --- | --- |
| 支出金额 | `-` + `¥` + 千分位两位小数 | `-¥51.10` |
| 退款金额 | `+` + `¥` + 千分位两位小数 | `+¥51.10` |
| 实付金额 | 绝对值，不带符号 | `¥51.10` |
| 千分位大额 | 千分位 + 两位小数 | `-¥1,286.00` |
| 时间 | `yyyy-MM-dd HH:mm`，24 小时制 | `2025-05-16 13:28` |
| 里程 | 千分位整数 + ` km` | `18,426 km` |
| 车牌 | 原样展示（含间隔点） | `粤B·D82K6` |
| 标签 | `#` + 文本 | `#谷电错峰` |

- 金额全链路整数分，禁止浮点累加；展示层四舍五入到分。
- 时间按设备本地时区展示；接口返回带偏移量的 ISO 8601，客户端解析后统一格式化，不做二次时区换算。
- 分类徽标文案 P0 由客户端映射；P1 改为后端返回 `categoryLabel`，客户端仅兜底。

### 7.3 状态推导

- `amountCents >= 0` → `completed`，文案「已完成」，绿色对勾。
- `amountCents < 0` → `refunded`，文案「已退款」，玫粉回退图标；结算卡标题改「退款金额」。
- 若后端显式返回 `status`，以后端为准；两者冲突时前端记录埋点并按后端渲染。

## 9. 全局状态与异常

| 场景 | 处理 |
| --- | --- |
| 进入时列表已有该记录 | 用列表记录先渲染，再拉详情补齐标签 / 备注 / 支付渠道；不闪骨架 |
| 进入时无记录快照 | 骨架屏，700ms 内出内容；超时显示重试 |
| 详情返回 404 | 空态「记录不存在或已被删除」，隐藏分享 / 更多，底部按钮禁用 |
| 备注保存时记录被删除 | 关闭浮层，Toast「记录已被删除」，返回账单并刷新 |
| 标签达到 8 个 | 「添加标签」置灰，点击 Toast「最多添加 8 个标签」 |
| 标签重复 | 输入框内提示「标签已存在」，保存按钮禁用 |
| 备注全为空格 | 视为清空，保存后显示空备注占位 |
| 金额异常（超过 8 位整数） | 自动缩小字号，禁止横向滚动 |
| 车辆已删除 | 展示快照 + 「已解绑」，隐藏箭头 |
| 支付渠道未知枚举 | 显示后端 `label`；无 label 显示「其他」+ 中性圆点；完全缺失显示「未记录」 |
| 系统返回手势 | 优先关闭已打开的浮层；无浮层时返回账单 |
| 低内存重建 | 通过路由参数中的 id 重新拉取，不依赖页面内临时状态 |
| 重复点击底部按钮 | 首次点击后 300ms 内忽略再次点击 |
| 时区 / 跨零点 | 交易时间不重算，保持记录时本地时间 |

| 无障碍 | 返回 / 分享 / 更多 / 底部按钮命中区 ≥ 44×44；摘要卡读屏合并为「充电，特来电充电站，支出 51.10 元，已完成，5 月 16 日 13:28」；标签读屏为「标签 日常补能」 |
| 对比度 | 正文 ≥ 4.5:1，大号金额 ≥ 3:1；浅色分类文字使用深色变体 |
| 隐私 | 分享 / 复制默认隐藏车牌；不展示用户手机号、支付账号尾号（`payment.detail` 仅内部字段，P0 不渲染） |
| 离线 | 只读快照可见；编辑 / 删除 / 分享在离线时提示失败，不排队 |
| 日志 | 不打印备注全文与车牌；错误只上报错误码与 traceId |
| 国际化 | 本期仅中文；金额、时间格式集中在格式化层，便于后续本地化 |

## 12. 验收清单

- [ ] 从账单页点击任意一条记录可进入本页，返回后账单页滚动位置与筛选条件不变。
- [ ] 有列表快照时无整页骨架；无快照时骨架在 1s 内被内容替换。
- [ ] 摘要卡金额、标题、分类徽标、状态、时间与账单卡片一致。
- [ ] 支出显示 `-¥`，退款显示 `+¥`，状态分别为「已完成」「已退款」。
- [ ] 车辆卡显示记账时名称、车牌、里程；车辆删除后显示「已解绑」并隐藏箭头。
- [ ] 结算卡四行字段与接口一致，「实付金额」不带负号。
- [ ] 支付渠道未记录时显示「未记录」且无圆点。
- [ ] 标签最多 8 个，超限禁用添加；标签自动带 `#`，重复标签无法保存。
- [ ] 备注编辑浮层支持 200 字计数、取消、保存；保存后卡片原地更新。
- [ ] 备注为空时显示占位文案，点击可编辑；超过 4 行可展开 / 收起。
- [ ] 分享面板打开且文本包含分类、标题、金额、时间、车辆简称，不含车牌。
- [ ] 删除有二次确认，确认后返回账单、Toast「已删除」，账单汇总与列表刷新。
- [ ] 删除失败保留本页并提示；404 视为删除成功。
- [ ] 记录不存在时显示空态，隐藏分享 / 更多，底部按钮禁用。
- [ ] 加载失败可重试，重试成功恢复内容。
- [ ] 底部「再记一笔」「编辑此笔账单」在记账页未接入时给出明确 Toast，不崩溃。
- [ ] 深色模式下卡片、文字、按钮均使用暗色 token，无白底闪烁。
- [ ] 系统字号 1.3 倍时无文字截断、无横向滚动；金额自动缩放。
- [ ] 读屏可完整朗读摘要、车辆、结算、标签、备注与两个底部按钮。
- [ ] `flutter analyze` 与 `flutter test` 通过，新增测试覆盖金额 / 状态 / 标签 / 删除流程。
