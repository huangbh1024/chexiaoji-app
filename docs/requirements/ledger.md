## 1. 背景与目标

首页回答「这个月花了多少、花在哪」，账单页回答「**每一笔都记了什么、能不能找到并改掉**」。它是账本类产品的核心工作页，也是用户回看、核对、补录、导出数据的入口。

账单页要在一屏内回答：

1. 这个月（可切月份）**一共花了多少**，比上月多了还是少了？
2. 钱主要花在**能源还是维保**上？哪一天最异常？
3. 具体**每一笔**的金额、分类、车辆、电量/油量/里程/时长等明细是什么？
4. 换一辆车、只看某一类开销时，**还剩哪些记录**？

设计目标：

- 汇总与流水在同一页完成，不做二级切换；
- 车辆、分类筛选 1 次点击生效，横向滑动即可看到全部选项；
- 流水按天分组，组头直接给出「几笔、多少钱」，不需要心算；
- 记录卡在左侧给「是什么」，右侧给「多少钱 + 一项关键衍生指标」，扫视即可浏览；
- 列表可无限下拉，3 年数据也不卡顿。

## 2. 用户与典型场景

| 用户 | 场景 | 关注点 |
| --- | --- | --- |
| 一人多车 | 月底对账 | 全部车辆合计多少，各车分别多少 |
| 纯电车主 | 核对充电账单 | 电量、里程、每公里成本是否异常 |
| 燃油车主 | 记录加油 | 升数、单价、油品、里程 |
| 混动车主 | 油电混合支出 | 能源合计、油电占比 |
| 记账习惯用户 | 补录、纠错 | 找到某天某笔并修改 |
| 报销 / 家庭共用 | 导出 | 月度明细导出 |

典型场景：

- **充电后**：打开账单页，确认这一笔已记录、金额与电量正确。
- **月初复盘**：切换月份，看总额、环比、日波动峰值，定位异常日。
- **只查某辆车**：点车辆 chip，汇总与流水同时切换。
- **只看保养**：点「保养」分类 chip，快速核对维保支出。
- **补一笔**：点中央 FAB 进入记账页，保存后回到账单页看到新记录。

- 页面外边距 16px；顶部栏与汇总卡间距 8px；汇总卡与筛选区间距 12px；筛选区与流水区间距 12px。
- 汇总卡圆角 **32px**、内边距 20px、1px `#EFF4FF` 描边 + 卡片阴影。
- 记录卡圆角 16px、内边距 12px、1px `#E5EEFF` 描边、阴影 `0 4px 16px rgba(15,23,42,.02)`。
- 图标容器 44×44、圆角 16px；分类 chip 全圆角；车辆 chip 全圆角。

- 汇总卡内：月份行与金额行 12px，金额行与子指标 20px，子指标与柱状图 12px。
- 汇总卡装饰：右上 176×176 `#63FCC0` @20% 光斑（blur 40），左下 144×144 `#C9E6FF` @25% 光斑（blur 24），不遮挡内容。

### 4.4 动效

| 场景 | 效果 |
| --- | --- |
| 切换月份 / 车辆 / 分类 | 汇总卡与列表 200–300ms 淡出 → 数据替换 → 淡入；筛选 chip 选中态 150ms 过渡 |
| 汇总金额变化 | 数字不做逐位滚动，随整块淡入；柱状图柱子高度 400ms 缓动 |
| 分页加载 | 底部 24px 转圈；新数据插入时列表不跳动 |
| 下拉刷新 | 系统 RefreshIndicator，主色 |
| 记录点击 | 卡片按下缩放 0.98 + 涟漪，进入详情 250ms 转场 |
| 底部 Tab 切换 | 保留各 Tab 滚动位置（IndexedStack） |

### 4.5 适配

- 竖屏，内容区最大宽度 448px 居中。
- 覆盖 375–430pt；左右安全区 + 底部安全区。
- 顶部栏 sticky（64px，背景 86% + 16px 模糊）；底部导航 fixed。
- 内容底部预留 112px + 安全区，避免被导航栏与 FAB 遮挡。
- 明暗两套主题；深色稿未出，按首页 `AppPalette.dark` 推导。

## 6. 模块需求

### 6.1 顶部栏

**展示内容**

- 左侧 36×36 圆形图标容器（底 `#EFF4FF`，1px 描边，绿色 `receipt_long` 图标 20px）。
- 图标右侧标题「账单明细」（20px / 700）。
- 右侧两个 36×36 白色圆形按钮（轻阴影）：
  - 导出（`ios_share`）：打开导出面板。
  - 筛选（`tune`）：打开筛选面板；**存在非默认筛选条件时**右上角显示 6×6 绿色圆点。

**交互与规则**

- 顶部栏固定，背景 86% + 模糊，内容从其下方滚过。
- 导出：P1 提供「导出本月 CSV / 生成长图」两个选项；本期无实现时点击 Toast「导出功能开发中」。
- 筛选面板（P1）包含：排序（时间倒序 / 金额倒序 / 分类）、金额区间、支付方式。面板内改动立即生效，可「重置」。
- 筛选圆点只在「排序非默认、金额区间、支付方式、分类非全部类型、车辆非全部」任一条件生效时出现（设计稿在全部类型下也显示了圆点，见 Q6）。
- 状态栏文字亮度随明暗主题。

**验收**

- [ ] 顶部栏滚动时固定，毛玻璃可见内容穿过。
- [ ] 标题为「账单明细」，图标与两个按钮位置、尺寸与设计稿一致。
- [ ] 有非默认筛选时出现绿点，重置后消失。
- [ ] 深色模式下无白块闪烁。

### 6.2 月度汇总卡

**展示内容**

| 区域 | 内容 | 样式 |
| --- | --- | --- |
| 第一行左 | 月份胶囊「2024年6月」+ `expand_more` | 16/700，底 `#EFF4FF`，全圆角，高 32 |
| 第一行右 | 环比胶囊：箭头 +「较上月 -12.0%」 | 11/600，下降：`#63FCC0`@30% 底 + `#004A33` 字；上涨：玫红 30% 底 + 白/深红字 + `trending_up` |
| 第二行 | `¥` + 整数（38/800）+ 小数（11/400）+ 右侧「共 16 笔支出」 | 小数与整数基线对齐，右文案 11px 次要色 |
| 第三行 | 三列：能源电油 / 维保服务 / 日均开支 | 标签 10/700 次要色；数值 16/700；列间 1px 竖分隔，第一列无 |
| 第四行 | 「当月日开销波动」+ 右侧「峰值 6/15 (¥480)」 | 10/700；峰值文案主色 |
| 第五行 | 日开销迷你柱状图 | 高 36，柱宽 6，圆角全，底部对齐 |

**数值与颜色**

- 能源电油：绿色 `#00C48C`。
- 维保服务：橙色 `#FC9D41`。
- 日均开支：主文字色。
- 环比下降：绿色系；上涨：玫红（与首页 Hero 一致）。

**日开销柱状图规则**

- 柱数 = 当月 1 日到「今天（含）」的天数；查看历史月份 = 该月总天数。
- 柱子高度 = 8px + 24px ×（当日金额 ÷ 当月单日峰值），取整到 2px；无记录日固定 8px。
- 柱子颜色：取当日金额最大分类的语义色，以约 45% 不透明度绘制；无记录日为 `#E5EEFF`。
- **今天**的柱子用主色 100% 绘制，并加 2px `#63FCC0` 外环。
- **峰值日**叠加 2px 橙色环；若峰值日即今天，今天样式优先，峰值标注照常显示。
- 峰值标注格式「峰值 M/D (¥金额整数)」；当月无记录时隐藏峰值标注，柱状图显示全底座，并在下方显示「本月还没有记录」。

**计算口径**

- 汇总卡跟随 **月份 + 车辆筛选**，**不跟随**分类 / 金额 / 排序筛选（分类筛选只作用于列表，见 §6.3）。
- 总额 = 该月该车辆集合全部记账金额之和（支出为正数累加，退款按负额抵扣）。
- 笔数 = 该月该车辆集合的记录条数（不含草稿、已删除）。
- 能源电油 = 充电 + 加油。
- 维保服务 = 保养 + 洗车（养护服务类）；设计稿示例数值与流水不自洽，见 Q1。
- 日均开支 = 总额 ÷ 当月自然日天数（设计稿 1,120.50 ÷ 30 = 37.35）。
- 环比 =（本月总额 − 上月同口径总额）÷ 上月总额 × 100%，保留 1 位小数；上月为 0 或无数据 → 显示「较上月 —」且不显示箭头。
- 全部车辆视图：总额、笔数、日波动均为所有车辆合计。

**交互**

- 点月份胶囊 → 底部弹层月份选择器（年 / 月网格）；默认当前月；可选范围：最近 36 个月，禁止选择未来月份。
- 切换月份：汇总卡与列表同时刷新，列表回到顶部并重置分页。
- 点环比胶囊无行为（本期）。
- 点柱子：显示该日 Tooltip（日期 + 金额 + 笔数），再点一次或点空白关闭（P1）。

**状态**

- 加载：金额、子指标、柱状图位置显示骨架条。
- 空月：总额 `¥0.00`、「共 0 笔支出」、三项为 `¥0.00`、柱状图全底座。
- 错误：汇总卡内显示「汇总加载失败 · 重试」，不影响列表已加载数据。

**验收**

- [ ] 月份选择器可切到任意历史月，未来月份置灰。
- [ ] 总额整数 38px、小数 11px，375pt 下不换行、不裁切。
- [ ] 三列子指标数值颜色正确（绿 / 橙 / 主文字），首列无左分隔线。
- [ ] 柱数、颜色、峰值标注与口径一致；今天带绿环、峰值为橙色。
- [ ] 环比上涨为玫红、下降为绿色；上月无数据显示「—」。
- [ ] 全部车辆时总额 = 各车汇总之和。

### 6.3 筛选区

#### (a) 车辆 chips

- 横向滚动单行，间距 8px，隐藏滚动条，首尾与页面边距对齐。
- 第一个 chip 固定为「全部车辆 (N)」，N = 车辆总数；选中态：深色底 `#0B1C30` + 浅色字 + 车辆图标。
- 其余 chip：白底、1px `#E5EEFF` 描边、轻阴影；前置 8px 圆点，颜色按动力类型（EV 绿 / HEV 橙 / PHEV 蓝 / ICE 琥珀）；文案为车辆名，单行不换行。
- 单选。选中某辆车时该 chip 使用深色底（与「全部车辆」一致），全部车辆 chip 恢复未选中态。
- 车辆超过 6 辆时横向滚动可见，不做「更多」菜单。

#### (b) 分类 chips

- 横向滚动单行，间距 8px。
- 选项：全部类型、充电、加油、保养、停车、过路费、洗车、保险 / 其他（设计稿缺少「洗车」但流水中有洗车记录，见 Q4）。
- 未选中：白底、1px `#E5EEFF` 描边、11px 次要色文字 + 12px 分类色图标。
- 选中：`#63FCC0`@40% 底、`#002114` 文字、主色 @30% 描边、加粗。
- 单选；切换后立即刷新列表并回到顶部。

#### (c) 联动与持久化

- 车辆、分类筛选变化时：列表重新请求；汇总卡只在车辆变化时刷新。
- 筛选条件在本页会话内保留（切到其他 Tab 再回来不重置）；退出 App 后是否记住见 Q7。
- 分类筛选生效时，在列表首条前插入结果提示条：「已筛选：保养 · 1 笔 · ¥480.00」，右侧「清除」。该提示条不参与时间分组。
- 选中的车辆与首页 `selectedVehicleIdProvider` **互不影响**（首页始终单车，账单页默认全部车辆），见 Q8。

- [ ] 分类 chip 选中态为浅绿底 + 深绿字 + 图标，且唯一。

### 6.4 流水时间线

#### (a) 分组规则

- 按记录发生日期（本地时区）倒序分组；组内按发生时间倒序，无时刻的记录排在当日末尾。
- 组头左侧 6×14 圆角色条，颜色 = 当日金额最大分类的语义色；今天固定为品牌绿。
- 组头标题：`今天 · 6月28日` / `昨天 · 6月27日` / `前天 · 6月26日` / `6月20日 · 周四`；跨年显示 `2025年12月31日 · 周三`。
- 组头右侧：「N 笔 · 共 ¥95.30」，N 与金额均按当前筛选后的结果统计。

#### (b) 记录卡内容

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 左 | 44×44 圆角方块图标 | 底色为分类色 12%–25% 浅底；图标 24px 分类色；充电 / 加油用实心图标 |
| 标题 | 商家 / 站点 / 项目名 | 15/700，单行省略 |
| 标题徽标 | 车辆简称（汉 EV / 凯美瑞）或元信息（B2区） | 10/700，圆角 4，浅底；车辆徽标按动力着色 |
| 副标题 | 分类相关明细，` · ` 连接 | 11px 次要色，单行省略 |
| 右主 | `-¥51.10` | 16/800，右对齐；退款为正数且不带负号 |
| 右副 | 衍生指标胶囊 或 状态文案 | 胶囊：10/700，浅底 + 分类色；状态文案：11px 次要色 |

**副标题与右副的字段矩阵**

| 分类 | 标题示例 | 副标题组成 | 右副（优先胶囊，次选文案） |
| --- | --- | --- | --- |
| 充电 | 特来电快充 · 科技园站 | 电量 `38.5 kWh` · 里程 `18,426 km` | 胶囊「¥0.17/km」绿色 |

## 7. 数据口径与格式化

### 7.1 指标定义

| 指标 | 公式 | 边界 |
| --- | --- | --- |
| 月度总额 | Σ 当月记录金额（支出正、退款负） | 无记录 → 0 |
| 笔数 | 当月记录条数 | — |
| 能源电油 | Σ（充电 + 加油） | — |
| 维保服务 | Σ（保养 + 洗车） | 见 Q1 |
| 日均开支 | 月度总额 ÷ 当月自然日天数 | 总额 0 → `¥0.00` |
| 环比 |（本月总额 − 上月总额）÷ 上月总额 × 100% | 上月 0 / 无数据 → 「—」 |
| 当日金额 | Σ 当日记录金额 | 无记录 → 0 |
| 当月单日峰值 | max(当日金额) | 全 0 → 无峰值标注 |
| 每公里成本 | 单笔金额 ÷ 该笔里程 | 里程 ≤ 0 → 不显示胶囊 |
| 加油单价 | 单笔金额 ÷ 升数 | 升数 ≤ 0 → 不显示单价段 |
| 充电单价 | 单笔金额 ÷ 电量 | 电量 ≤ 0 → 不显示单价段 |

### 7.2 时间口径

- 月份以设备本地时区自然月划分（1 日 00:00 至月末 23:59:59）。
- 分组日期取记录 `occurredAt` 的本地日期；无时刻默认 00:00，排当日末尾。
- 环比基准月 = 当前月份减 1 个自然月（1 月 → 上年 12 月）。
- 跨年、跨月的「今天 / 昨天 / 前天」在页面重新进入或下拉刷新时重算。

### 7.3 格式化

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 总额 | 千分位、2 位小数，整数大字 / 小数小字 | `¥1,120` + `.50` |
| 明细金额 | 千分位、2 位小数，支出带 `-` | `-¥51.10` |
| 组头合计 | 千分位、2 位小数 | `共 ¥95.30` |
| 年月 | `YYYY年M月` | `2024年6月` |
| 组头日期 | 相对日 + `M月D日`（+ `周X`） | `今天 · 6月28日` |
| 里程 | 千分位整数 + km | `18,426 km` |
| 电量 | 1 位小数 + kWh | `38.5 kWh` |
| 升数 | 2 位小数 + L | `24.51 L` |
| 单价 | `¥` + 2 位小数 + `/L`、`/kWh` | `¥8.16/L` |
| 每公里成本 | `¥` + 2 位小数 + `/km` | `¥0.17/km` |
| 时长 | 1 位小数 + 小时，或 `x 小时 y 分` | `3.5 小时` |
| 空值 | 统一 `—` | `—` |

## 9. 全局状态与异常

| 状态 | 表现 |

## 10. 非功能需求

- **性能**：冷启动进入账单 Tab ≤ 1s 可交互；切换筛选后首屏数据 ≤ 500ms（有缓存 ≤ 120ms）；1000 条记录滚动 60fps；分页请求 ≤ 1.5s（P90）。
- **内存**：列表使用懒构建，不一次性渲染全部记录；同时持有的页数上限 10 页（约 300 条），超出时释放最早页（如需回看则重新请求）。
- **稳定性**：分页游标重复 / 缺失时去重按 `id`；任何单模块失败不白屏；筛选请求可取消。
- **主题**：浅色 + 深色全量适配；深色下卡片、分隔线、柱状图底座、分类浅底需重新取值保证对比度 ≥ 3:1。
- **无障碍**：记录卡整体朗读为一句（「11月14日，充电，特来电快充科技园站，51.10元，汉EV」）；金额读作「元」而不是「¥」；筛选 chip 提供 `selected` 语义；字号放大 1.3 倍时金额不截断。
- **本地化**：本期仅中文、人民币、公里、kWh、L；文案集中管理。
- **隐私**：车牌、地点、商家名不进日志与埋点明文；导出文件仅保存在用户选择的本地路径。

| Q13 | 是否允许负金额（退款 / 报销）以及如何展示？ | 金额口径 | 允许，展示为正数并加「退款」标签，不计入「支出笔数」 |

| Q15 | 车辆数量上限 10 辆时，账单页 chip 是否仍然全部平铺？ | 筛选区体验 | 平铺横滑，不做「更多」；超过 10 辆再评估 |
